## Licensing Limitation

Some capabilities demonstrated in the training require Microsoft Entra, Microsoft Defender, Microsoft 365, Defender for Cloud Apps, Microsoft Purview, or Copilot Studio licensing.

If a feature is unavailable in the current tenant, no unsupported workaround is used.

Instead, the following are documented:

1. Required feature
2. Required configuration
3. Expected behavior
4. Licensing/tenant limitation
5. Security purpose

This ensures that the lab remains technically accurate without misrepresenting unavailable functionality.

## Security

Do not upload:

* Passwords
* API keys
* Client secrets
* Access tokens
* Certificates/private keys
* Personal information
* Sensitive organizational information
* Confidential tenant data
