
# Microsoft Defender XDR - AI Agent Discovery

## Objective

The objective is to discover AI agents operating within the organization.

## Why Discovery Matters

Security teams cannot protect agents that they do not know about.

Discovery helps identify:

- Number of agents
- Agent identities
- Agent platforms
- Connected resources
- Agent activity
- Potential security risks
