
# Copilot Studio Agent Security

## What is Copilot Studio?

Microsoft Copilot Studio is a platform for building AI agents and copilots with low-code/no-code capabilities.

## Security Considerations

Agents created through Copilot Studio may interact with:

- Organizational data
- Connectors
- APIs
- Applications
- Business workflows

## Security Controls

Security teams should evaluate:

- Agent identity
- Permissions
- Connectors
- Data sources
- Authentication
- Tool access
- Runtime activity
- Lifecycle

## Key Principle

An agent should have access only to the resources required for its defined business function.
