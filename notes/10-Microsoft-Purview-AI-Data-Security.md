
# Microsoft Purview - AI Data Security

## Objective

Microsoft Purview helps organizations discover, classify, protect, and govern sensitive data.

## AI Security Use Cases

Security teams can investigate:

- AI usage
- Sensitive data exposure
- Data loss risks
- Generative AI usage
- Sensitive information handling

## Important Controls

### Sensitivity Labels

Sensitivity labels can classify and protect organizational information.

### Data Loss Prevention

DLP can help prevent sensitive information from being shared with unauthorized applications or services.

### Insider Risk

Insider risk capabilities can help identify potentially risky user behavior.

### Audit

Audit capabilities provide visibility into relevant user and system activities.

### eDiscovery

eDiscovery can support investigation and compliance processes.

## Security Goal

Ensure AI systems do not bypass existing organizational data protection controls.
