# AI Agent Security Overview

## What is an AI Agent?

An AI agent is an AI-powered system capable of performing tasks, using tools, accessing data, and taking actions based on instructions.

## Chatbot vs AI Agent

A traditional chatbot generally responds to user questions.

An AI agent can:

- Access data
- Call tools
- Invoke APIs
- Perform tasks
- Take actions
- Interact with other systems or agents

## Why AI Agent Security Matters

AI agents can introduce additional attack surfaces.

If an agent is compromised and has excessive permissions, an attacker may potentially use the agent's privileges to access organizational resources.

## Main Security Risks

- Excessive permissions
- Compromised agent identity
- Sensitive data exposure
- Unsafe tool invocation
- Shadow AI
- Unauthorized access
- Agent-to-agent trust
- Inadequate lifecycle management

## Security Approach

AI agent security should use a layered approach:

1. Identity security
2. Least privilege
3. Conditional Access
4. Monitoring
5. Threat detection
6. Runtime protection
7. Data protection
8. Governance
