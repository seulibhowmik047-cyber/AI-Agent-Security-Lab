
# Lab 01 - Microsoft Entra Agent Identity

## Objective

To understand how AI agent identities are represented and managed in Microsoft Entra.

## Portal

Microsoft Entra admin center

## Procedure

1. Sign in to Microsoft Entra.
2. Navigate to the Agents section.
3. Review available agent identities.
4. Review agent users.
5. Review agent blueprints.
6. Review owners and sponsors.
7. Review available permissions.
8. Review agent attributes.

## Expected Result

The administrator should be able to identify agent identities and review their configuration.
