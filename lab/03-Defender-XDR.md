# Lab 03 - Microsoft Defender XDR

## Objective

Discover and assess AI agents using Microsoft Defender XDR.

## Procedure

1. Open Microsoft Defender portal.
2. Navigate to the AI/agent security area where available.
3. Review discovered agents.
4. Select an agent.
5. Review its identity.
6. Review permissions.
7. Review connected resources.
8. Review risk information.
9. Investigate possible attack paths.
10. Document findings.

## Evidence

Capture screenshots of:

- Agent discovery
- Agent details
- Permissions
- Risk information
- Attack path information

## Licensing Note

Some AI agent discovery and security capabilities may require Microsoft 365/Defender licensing and additional connectors.
