# Lab 02 - Conditional Access for AI Agents

## Objective

Understand how Conditional Access can control AI agent authentication and access.

## Procedure

1. Open Microsoft Entra.
2. Navigate to Conditional Access.
3. Create a test policy.
4. Select the appropriate agent identity target where supported.
5. Configure relevant conditions.
6. Configure grant/session controls.
7. Set the policy to Report-only.
8. Review the effect.
9. Validate the policy.
10. Enable enforcement only after successful testing.

## Important

Do not immediately enable a production Conditional Access policy.

Always validate the policy using Report-only mode first.

## Expected Result

The policy should evaluate the applicable authentication request and allow, block, or apply the configured control.

## Evidence

Add screenshots showing:

- Policy configuration
- Target identity
- Conditions
- Grant controls
- Report-only status
