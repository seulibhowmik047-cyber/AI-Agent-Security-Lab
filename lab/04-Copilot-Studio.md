# Lab 04 - Copilot Studio Agent Security

## Objective

Understand security controls for agents created using Microsoft Copilot Studio.

## Procedure

1. Open Copilot Studio.
2. Review available agents.
3. Select an agent.
4. Review authentication.
5. Review connectors.
6. Review knowledge sources.
7. Review actions/tools.
8. Identify required permissions.
9. Review security controls.
10. Document the agent configuration.

## Security Checklist

- [ ] Authentication configured
- [ ] Least privilege applied
- [ ] Knowledge sources reviewed
- [ ] Connectors reviewed
- [ ] Tool permissions reviewed
- [ ] Sensitive data access reviewed
- [ ] Runtime protection considered
- [ ] Lifecycle process defined
